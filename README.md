# Carrom Bot Automation Framework

A modular computer vision and ADB-based automation prototype for testing game mechanics and touch input handling.

## Prerequisites

* Python 3.8 or higher installed on your computer.
* Android device with **USB Debugging** enabled in Developer Options.
* ADB (Android Debug Bridge) installed and added to your system path.
